## Classification Legend

- **A. PUBLIC_CORE** — Reusable framework; safe to import from.
- **B. PUBLIC_EXAMPLE** — Reusable example, not part of core.
- **C. CASE_STUDY_SIGMA_ABC** — sigma_abc-specific artifact. Defer
  migration to `case_studies/sigma_abc/`.
- **D. DEVLOG_LOOP_ENGINE** — Per-loop engineering reports. Routed
  to `docs/devlog/loop_engine/`.
- **E. DEVLOG_SIGMA_ABC** — Per-stage sigma_abc reports. Routed to
  `docs/devlog/sigma_abc/`.
- **F. GENERATED_ARTIFACT** — Generated by the runner. Routed to
  `archive/local_runs/` (one-off) or `autonomous_runs/` /
  `reports/` (per-invocation, gitignored).
- **G. LOCAL_PRIVATE** — This-machine-only config (e.g.,
  `agents/runtime.local.yaml`). Gitignored.
- **H. DELETE_OR_IGNORE** — Cache / metadata (`.DS_Store`,
  `__pycache__/`, `__MACOSX/`). Gitignored.
