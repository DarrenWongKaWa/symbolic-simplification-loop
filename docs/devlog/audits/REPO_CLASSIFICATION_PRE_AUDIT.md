# Repo Classification Pre-Audit

## Scope

Every top-level entry in `symbolic-simplification-loop/` is classified
into exactly one of: PUBLIC_CORE, PUBLIC_EXAMPLE, CASE_STUDY_SIGMA_ABC,
DEVLOG_LOOP_ENGINE, DEVLOG_SIGMA_ABC, GENERATED_ARTIFACT, LOCAL_PRIVATE,
DELETE_OR_IGNORE.

No files are moved in this step.
