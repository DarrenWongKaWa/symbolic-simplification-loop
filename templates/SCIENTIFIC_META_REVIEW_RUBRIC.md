# Scientific Meta-Review Rubric

Every scientific meta-review must answer these questions explicitly:

1. PASS as what?
2. NOT PASS as what?
3. What was actually validated?
4. What was only inherited or deferred?
5. What caveats must be preserved?
6. Was any overclaim detected?
7. Is freeze allowed?
8. Is human approval required before the next stage?
9. Which review lane was used and why?
10. What should the next safe stage be?

Preferred language:

```text
PASS as center-sector row-provenance conservation checkpoint.
NOT PASS as center-sector fused physical kernel formula.
NOT PASS as full tensorial sigma_abc correctness.
```

Reviewers must not convert inherited checks into direct checks.  In particular,
the permanent caveat must remain:

```text
DCProjectionTo1D -> INHERITED_PASS, not direct full tensorial DC-series PASS.
```
