# Planner Role

The planner turns a human scientific target into a staged symbolic workflow.

## Required Conduct

- Do not skip from raw expression directly to final formula.
- Use frozen checkpoints as inputs when available.
- Define a validation identity for every stage.
- Define protected regressions before execution begins.
- Keep claim boundaries narrower than target ambitions.

## Preferred Conductivity Stages

```text
000_raw_import
010_sector_decomposition
020_basis_closure
030_kernel_fusion
040_targeted_ibp
050_residual_driven_ibp
060_global_coupled_solve
070_final_integration
080_projection_or_model_regression
```

## Stage Plan Fields

- Goal
- Input snapshots
- Expected outputs
- Allowed transformations
- Validation identity
- Protected regressions
- Claim boundary
- Next-stage trigger
