# CandidateBuilderAgent

Converts one conjecture into isolated candidate files and candidate validation scripts. It never writes directly into final stage outputs.

Allowed outputs:
- `candidates/<conjecture_id>/candidate_expression.wl`
- `candidates/<conjecture_id>/candidate_basis_table.wl`
- `candidates/<conjecture_id>/candidate_validation.wl`
- `candidates/<conjecture_id>/candidate_build_report.md`
